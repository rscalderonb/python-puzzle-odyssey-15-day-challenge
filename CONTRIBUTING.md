# Contributing

Thanks for taking the time to improve this challenge set.

## Pull requests

- Keep PRs small and focused.
- Describe the change clearly in the PR body.
- Prefer improvements to existing solutions or additional alternative solutions over rewriting whole days.
- All pull requests are reviewed before merging.

## Issues

Feel free to open an issue if you find a problem statement that is ambiguous, a solution that does not work, or if you have an idea for a new exercise that fits the style of the set.
