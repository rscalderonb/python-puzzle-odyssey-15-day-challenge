# Python Puzzle Odyssey

A 15-day collection of 60 programming exercises in Python.  
Four problems per day, progressing from fundamentals to more involved logic, data handling, and algorithms.

These are original problems written in the spirit of classic short practice sets. They are meant to be solved with pure Python (standard library is welcome where it makes sense). Solutions are included so you can compare approaches after you have tried the problem yourself.

## How to use this repository

1. Clone or fork the repo.
2. Work through one day at a time.
3. Attempt each exercise before looking at the solution.
4. Feel free to improve solutions or add alternative approaches via pull request. All pull requests are reviewed before merging.

```bash
git clone https://github.com/rscalderonb/python-puzzle-odyssey-15-day-challenge.git
cd python-puzzle-odyssey-15-day-challenge
```

## Structure

- `days/` – one Markdown file per day containing the four exercises for that day.
- Each exercise follows the same format: **Question**, **Hints**, **Solution**.
